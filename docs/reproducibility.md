# ExecLens Benchmark Reproducibility & Audit Guide

This guide describes how to reproduce, verify, and audit benchmark reports generated by ExecLens.

---

## 1. Prerequisites & Environment Fingerprint

To reproduce ExecLens benchmarks, ensure the base toolchain is installed:

- **Go**: 1.22+ (recommended 1.24+)
- **Node.js**: 18+ and npm 9+
- **Compilers**:
  - `g++` (GCC 11+)
  - `rustc` (Rust 1.70+)
  - `javac` and `java` (OpenJDK 17+)
  - `python3` (CPython 3.10+)
  - `node` (Node.js 18+)

ExecLens records the complete environment fingerprint in every report, including CPU model, logical cores, operating system, and toolchain versions.

Inspect your host environment anytime via CLI:
```bash
./execlens languages
./execlens accelerators
```

---

## 2. Reproducing Benchmark Runs

### 2.1 Complete End-to-End Workflow

To execute benchmarks, produce publication-ready reports, render vector SVG charts, and update `README.md`:

```bash
make benchmark-report
```

This single command:
1. Runs multi-language benchmarks and stores immutable observations in SQLite.
2. Invokes the report generator to calculate statistics, 95% Confidence Intervals, and speedup ratios.
3. Renders 10+ standalone vector SVG charts.
4. Generates `summary.json`, `raw-results.json`, `comparison.csv`, `report.md`, and `report.html`.
5. Updates the designated section in `README.md`.
6. Executes `make report-verify` to ensure all links and schemas conform to specification.

### 2.2 Generating Reports from Recorded Data

If you have already executed benchmarks and wish to re-generate reports (e.g. altering the comparison baseline or recalculating statistics):

```bash
# Re-generate report from existing database
make report

# Re-generate with specific baseline (e.g. Rust instead of C++)
./execlens report-gen --baseline=rust
```

## 3. Auditing & Cryptographic Verification

ExecLens includes an automated verification command (`make report-verify`):

```bash
make report-verify
```

The verification command validates:
1. **Artifact Integrity**: Confirms all 15 core report files and charts exist and are non-empty.
2. **Schema & Value Conformance**: Validates that JSON files contain well-formed schemas with no `NaN` or `Infinity` floats.
3. **Cryptographic Checksums**: Re-computes SHA-256 hashes of every generated file on disk and verifies that they match `manifest.json`.
4. **Link Resolution**: Confirms that every image reference `![...](charts/...)` in `report.md` and `README.md` resolves to an existing file.
5. **Boundary Integrity**: Verifies that `README.md` contains valid, un-inverted markers (`<!-- EXECLENS_REPORT_START -->` and `<!-- EXECLENS_REPORT_END -->`).

---

## 4. Deterministic Reproducibility Check

ExecLens reporting is 100% deterministic. When executed against identical input data, re-running the generator produces bit-for-bit identical SVG charts, markdown reports, and JSON summaries.

You can verify reproducibility manually:

```bash
# First generation
./execlens report-gen --output=reports/test1
sha256sum reports/test1/manifest.json

# Second generation with same input
./execlens report-gen --output=reports/test2
sha256sum reports/test2/manifest.json

# Compare checksums
diff -r reports/test1/charts reports/test2/charts
```
